An AI website generator that ships a live site in 10 seconds.

Zuri matches a business description to the best of 80 hand-built templates, then generates the copy to fill it, turning an idea into a working website before the user finishes their coffee.

The problem

Most small businesses in Nigeria don't have a website, and the reason usually isn't cost, it's that building one properly takes a developer, a few weeks, and a back-and-forth most business owners don't have time for. Zuri exists to collapse that gap: describe the business, and get a live, well-designed website in the time it takes to describe it.

How it works

A user goes through a short onboarding flow describing their business. Zuri matches that description against a library of 80 hand-built templates, selects the closest fit, generates copy tailored to the business with the Gemini API, and selects imagery to match — not placeholder text, not a generic mad-lib. The full pipeline, from the end of onboarding to a live URL, takes around 10 seconds.

The hardest decision

The first version generated websites directly with AI, from scratch, for every request. It didn't hold up. Output quality and code structure were inconsistent, there was little real control over the result, and the API cost of generating a full site from nothing for every user was not sustainable at any real scale.

The tradeoff

Moving to a system that matches businesses to a curated set of 80 hand-built templates and generates only the copy; not the structure - cost more deliberate upfront work and ongoing API spend per generation. In exchange, output quality and design consistency went up sharply, and the result is a site that actually looks like it was built with care, not assembled by a model guessing at layout.

Where it stands

Zuri is live as an MVP with 17 generations completed, and is currently in the judging window for the Gemini X Prize. The next stage of work is scaling the template library, tightening generation cost per site, and moving from MVP to a product businesses can rely on long-term.
