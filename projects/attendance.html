Attendance Management Portal

A database-backed attendance tracker built for a church youth community, replacing a paper register with weekly check-ins, member profiles, and simple analytics.

Role

Solo: design & engineering

Stack

HTML, CSS, JavaScript, Google Sheets + Apps Script

Timeline

Built and deployed independently

Client

Confidential, details on request

The problem

The community was tracking weekly attendance on paper, slow to update, easy to lose, and impossible to get any real insight from. There was no budget for a hosted database or backend service, so the solution had to run on infrastructure that already existed and cost nothing to maintain.

The approach

I built the entire interface from scratch in HTML, CSS, and JavaScript, and used Google Sheets as the database with Google Apps Script acting as the backend API. No hosting costs, no server to maintain, and a data store the organizers could still open directly if they ever needed to.

  • Weekly attendance marking, built to be fast enough to use live during a Sunday session.
  • Member management: adding new members and viewing or editing existing profiles.
  • Lightweight analytics, turning weeks of raw check-ins into attendance trends the organizers could actually use.

The main technical challenge was automating what had been a fully manual process, designing the Sheets structure and Apps Script functions so the app could read and write reliably without a traditional backend.

The outcome

The portal is in active use, and attendance tracking that used to depend on a paper register and someone's memory now takes a few taps, with the data to back it up.
